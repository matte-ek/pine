# Game ideas

The games planned for Pine. Each one has a page describing the game and listing the engine
features it needs, checked against the engine as it was when the page was written. Together they
decide which engine work comes next: a feature several games need matters more than one only a
single game needs.

When a feature lands, tick it on every game page that lists it and update the table below.

| Game | Status | Page |
|------|--------|------|
| Slender-style forest game | Idea | [slender.md](slender.md) |
